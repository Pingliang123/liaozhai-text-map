## 一、研究目的與不可違反的原則

論文題目：**異境、異人與異事：《聊齋志異》中的空間書寫**。作者馮宇，香港中文大學。

研究關心「異」如何由人物、事件及穿梭或停留的空間共同構成。數字人文分析應從全書比較發現問題，再回到全部命中樣本及反例，不能只換一種方式展示熟悉篇目的細讀。需要進一步回答：空間的進出、佔用、隔斷和轉換，如何限制人物的財產、身分、支配權與生存處境。

理論背景涉及龍迪勇的故事空間、形式空間、心理空間、存在空間，以及黃霖等人的藝術空間、創作空間、接受空間。現有詞彙與路徑資料主要能處理故事／藝術空間，不能聲稱已分析全部層面。詞頻、共現與投影都不能單獨證明空間具有敘事主體性。

必須遵守：

1. 保留使用者全部人工修改。自動抽取、舊備份與生成流程不能覆蓋新修訂。
2. 地圖、網絡、人物路徑都以原文及有效分詞為依據。合理推定須保留依據，不能虛構原文沒有的端點或人物行程。
3. **空間詞＝地點詞＋場所詞**。舊介面稱「空間詞」的細尺度詞，現在稱「場所詞」。內部 `space_words` 等欄名未全面更名，以保持相容。
4. 篇目類型為人、鬼、狐、妖、神，允許重疊。異事類型、LDA主題、人工詞群、使用方式、世界分類是不同維度。
5. 地點別名與行政上下級分開處理；同座標不必然同一實體。歷史歸屬須留意時期，異境不能強套現實座標。
6. 簡化文字與功能，避免重複入口和堆疊網絡。研究分析目前保存在本機，未經新要求不要自動上線。
7. 每次改動須有相應測試／驗證及 Git commit；只提交本次檔案，不捲入其他工作。
8. 報告、程式、提示詞不得收錄對話中的 API 金鑰或授權憑證。
