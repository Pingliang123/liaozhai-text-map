# 文本地图与空间实验室检查记录（2026-10-22）

## 数据

核对了仓库人工修订、总资料包、网页数据入口、实验室实时读取、层级记录及派生统计。与本轮开始时的仓库版本逐项比较，491 篇人工修订、143 条定位修订均未改变。新增 `complete_snapshot` 仅区分完整修订与旧版残缺文件，不重新判定词语、异事类型或地名。

`manual-revisions.json` 保存人工修订；`data-package.json` 是包含底本的发布资料包，两者修订必须一致。实验室从总资料包和同一浏览器的已保存修订建立视图，不以旧实验室快照覆盖人工资料。派生文件保留修订指纹，以便核对来源。

## 修复

- 地图与实验室之间只传递地名，不再混入层级符号、篇数。地图选点、下拉选择均更新网络入口。
- 正文的篇目研究按钮改到统一实验室；保留旧研究书签，避免直接删去旧入口导致失效。
- 篇目和异事筛选写入网址；篇内网络的选择使用独立参数，不误改全书筛选。网络范围、层级与参考年份可随网址恢复。
- 无结果时只显示空状态和清除筛选，不再显示无效图表控件。
- 网络 CSV 随当前网络范围、层级投影和显示条件更新。过期的异步请求不再替换当前标签内容或导出结果。
- “乡镇／村落”包括 `village`，不会漏掉蔡店等村落。
- 发布文件未变时复用总资料包；有效修订未变时不重画网络，避免切回视窗后丢失选点状态。
- 实时快照包含时间词；明确清空的时间词不再被旧静态文件补回。
- IndexedDB 保存改为同一事务内读取、合并、写入，多页面分别修改不同篇目不会互相覆盖；同篇冲突仍拒绝覆盖。一次保存失败后可以重试。
- 修订与资料包下载读取实际保存后端，并合并其他页面的已保存修改。修订导入上限可容纳现有完整导出文件。
- 上传过程中继续编辑时，保留已提交版本作为后续合并依据，不再与自己的提交冲突。
- 完整修订标记保护主动撤回，旧版残缺文件仍保留补全兼容。发布流程不再自动补回已移除的定位记录。
- 网站资源使用内容摘要更新版本号；资产与报告变化可以触发发布。
- ZIP 包纳入当前网页、代码、资产和总资料包，保留已有研究源文件；校验清单在最终构建完成后更新。
- 忽略本机 Wrangler 状态，避免把部署缓存放进仓库。派生分析报告纳入发布提交，避免线上文件与仓库脱节。

## 验证范围

本轮新增保存并发、失败重试、备份大小、完整撤回、实时时间词、页面状态、异步隔离和缓存失效的回归测试；原有词表、层级、图表、云端授权、NetworkX 和数据一致性测试一并运行。源码模型副本必须一致，既有人工修订内容另行比较保护。

同步后端使用原有 Cloudflare 服务更新，保留线上变量与授权范围；健康接口检查不写入用户资料。

## 边界

此次未重新分类全书词表，也未调用付费 AI。候选词、历史地理歧义及文学解释仍需原文核查，不能由功能测试代替。

浏览器控制连接超时，未完成真实设备的逐项点击验收。交互检查使用 DOM 回归测试；发布另以构建结果及线上文件校验。没有用用户的实际修订做写入演练。
