# 地点网络分类与辨读修正

原文核对：

- 《酒狂》：“夜于村外旷莽中”“送之郊外”。村外、郊外是场景方位。
- 《雹神》：“祠前有池”。祠是建筑通称；雹神李左车祠等专名不由后缀规则自动删除。
- 《辛十四娘》：“道侧故有兰若”“疑必村落”“归墓”。兰若、村落、墓按空间词处理。
- 《道士》：“已至寺门”；《罗刹海市》《长亭》：“入山村”。寺门、山村按空间词处理。

在独立研究页构图时把村外、祠、兰若、寺门、山村、村落、郊外、墓由地名候选移到空间词。原始标注、主站和人工修订不改写。空间词只有满足现有定位线索时才与地点连线，未归属者留在待查线索中。

以明确词名清单标记异境，朱红显示，例如冥府、阴司、天宫、仙人岛、罗刹国；不依靠名字包含“神”“鬼”等字泛化判定。《酆都御史》有“酆都县外”的地理语境，酆都不据冥府联想着色。龙宫在《罗刹海市》中也作为子女名出现，未据字面加入异境地名清单。词级分类仍需对照证据继续修订。

点选节点以橙色加粗突出所有相连边，淡化不相关节点，并提供取消高亮。全图所有节点保持原位。全图最低连线透明度由0.06调至0.20，同时加深线色；次数权重不改。
