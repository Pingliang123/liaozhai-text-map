## 重算所需資料及限制

`reports/research-handoff-inputs-20261117.zip` 是本輪分析快照，含原分析所用的整合包、選定詞輸入與完整詞彙登錄，以及逐檔 SHA-256 清單。壓縮包不是第二個可修改總資料庫；只用於重現既有分析。正式修訂仍以最新發布總包及有效人工修訂為準。

恢復腳本只寫入被 Git 忽略的 `.network-runtime/`，不更動 `data-package.json`，遇到不同的現存輸入會停止，避免覆蓋其他設備的新工作。已保存的圖表、JSON、CSV和報告均直接在 `reports/` 中。

需要重算時，Python 環境主要需要 numpy、scipy、scikit-learn、matplotlib、tqdm，LDA與Word2Vec另使用 qhchina 0.2.7。原腳本會優先搜尋 `.network-runtime/topic-libs`，也可從正常 Python 環境載入。請讓 Codex 根據實際 Python 版本建立隔離環境並檢查套件相容性。

部分繪圖腳本硬編碼 Windows 字體 `C:/Windows/Fonts/msjh.ttc`；另一系統或缺少該字體時，須改成當地可用中文字體後再生成，不能聲稱目前腳本已完全跨平台。Git與Python環境、登入狀態、瀏覽器本機修訂及本機憑證不會隨克隆轉移。其他設備尚未上傳的瀏覽器修改，仍需先備份或同步。

本機絕對路徑只適用舊電腦。新設備一律使用克隆目錄作基準；舊交接報告中提到的路徑，按倉庫相對路徑尋找即可。舊交接提示詞可作背景，跨設備操作請以本文件為準。
