# 篇目空间网络与同步整合

- 实验室第二张网络改为按篇目选择，展示该篇地点、空间、异境和原文关联。空间归属未明时保留独立节点。
- 全书地点网络、人物路径和历史层级仍可使用。篇目空间网络保留具体空间，不随省域投影消失。
- 文本地图移除重复的地区词汇比较和跨篇相似篇目面板，改为链接至实验室。本篇网络与原文可互相跳转。
- 两站继续共用 data-package.json，并叠加同一浏览器中的已保存修订；未改写人工修订、总资料包或词语分类。
- 保存备用修订后，等待 IndexedDB 事务完成再发出更新信号。实验室优先读取实际保存位置，避免 localStorage 旧副本遮住新修订。
- 实验室在跨标签页保存和重新切回窗口时更新资料；读取备用修订失败时显示错误，不以旧副本冒充最新资料。
- GitHub 自动提交与版本记录沿用现有同步后台。跨设备需云端提交成功及发布完成后读取新版。

验证：全书逐篇图结构、篇目切换、原文链接、人工数据一致性、备用储存与容量不足恢复；隔离浏览器验证真实 SVG 显示和地图修订保存。新增测试纳入发布流程。
